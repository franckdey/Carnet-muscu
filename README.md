# Carnet de muscu

Appli web installable (PWA) pour noter ses séances de musculation : machines (noms anglais et français), séries, reps, charges, cardio, historique, progrès et minuteur de repos.

- Les données restent sur le téléphone (stockage du navigateur). Onglet Historique → Sauvegarde pour exporter/importer.
- Installation sur Android : ouvrir le site dans Chrome → menu ⋮ → « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
- Mise à jour : modifier `index.html`, puis changer `VERSION` dans `sw.js`.
